# Second-row promotion banner

The second bracelet banner follows the second row of source cards, spanning
the full content grid. The desktop, tablet and mobile layouts place it after
six, four and two source cards respectively, ignoring the first advertisement.
The original first-row banner remains unchanged. If a Followed list has a
partial second row, the banner follows that row; lists with only one row
retain just the original banner.

Both images link exactly to `https://kailashenergy.com/vullnetdemiri`, opening
in a new tab with `sponsored noopener noreferrer`. Neither advertisement is a
source ID or a sortable item. Both keep the existing localized sponsorship
label and a translated image description in all twelve interface languages.

## Artwork and files

The portrait source was edited using the built-in **image_gen** tool, with
the surrounding wooden background extended horizontally into a 3:1 scene.
The output was inspected for a fully visible bracelet and round pendant.
There are no added slogans or product claims. This is an AI-assisted banner
adaptation, not a claim that the original photograph is pixel-identical.

The selected PNG is 2172×724. A workspace copy of the master is retained at
`.cache/second-bracelet-banner-master.png`. Production uses these WebP files:

## Exact image prompt

Use case: compositing / precise-object-edit. Asset type: photographic website advertisement banner, exactly 3:1 landscape composition, ideally 3072x1024. Input image is the EDIT TARGET, not a loose style reference. Expand its canvas horizontally into a continuous realistic dark wooden tabletop. Preserve the entire original bracelet arrangement and all objects together in the central third of the wide scene, with modest breathing room above and below. Keep the entire bracelet, carved face bead on the left, cream beads, brown disc and barrel beads on the right, hanging round tan pendant at lower left, and the small striped white bead inside the loop fully visible. Do not crop, stretch, replace, recolor, redesign, add or remove any product bead or pendant. Retain the warm aged painted manuscript at the upper right, existing colors, grain, texture, lighting and shadows; extend only the surrounding dark wood/background naturally toward both sides. Match the provided photo closely, no new product objects, no slogans, logos, prices, borders, panels, typography or watermarks. The output is ONE clean wide 3:1 image that fills the banner edge to edge, with the complete authentic source product centered and uninterrupted dark wood on both sides.
